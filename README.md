# Project presentation : 
This project implement a treatment and analysis pipeline for NIRS (Near InfraRed Spectroscopy). The main purpose is to study hemoglobin concentration variations regarding the mode of contraction and the intensity. 

The experimental design includes
    - 2 independants variables : contraction_mode (concentric vs eccentric) and intensity (30% vs 50%)
    - 1 dependant variable : EnvelopeMean_HbR_uM (at this day, might change with further analysis)
    - 23 subjects (repeated measures)
